# Token 高峰守卫

按 DeepSeek 的峰谷计费时段，把高峰期锁住，省 token。

DeepSeek API 工作日 09:00-12:00、14:00-18:00 是高价时段，其余时间半价。这期间本插件会把机器人锁住，除管理员外一律拦截；周末和法定节假日全天放行。时段、文案、放行范围都能自己改。

## 适用情况

- 自己养 bot，或者一群朋友共用一个小群，余额不算宽裕
- 高峰期容易被人闲聊刷掉一大截用量，想把对话赶到半价时段
- 出门在外，想一键锁死，回来再放开
- 只是想看看自己一天里哪个小时用得最凶

## 兼容平台

基于 AstrBot 通用消息事件实现，不绑定具体适配器：

| 平台 | 状态 |
| --- | --- |
| aiocqhttp（QQ / OneBot） | 已实测 |
| qq_official | 走 AstrBot 消息管线，生效 |
| telegram / discord / webchat | 同上 |

需要 AstrBot `>= 4.0.0`。

## 能做什么

- **高峰拦截**：到了高价时段，非管理员的消息直接拦住，回一句提示。同一会话有冷却，防止刷屏
- **锁死模式**：出门或余额告急时打开，连谷时也拦，只剩管理员能说话
- **四档放行范围**：仅管理员（默认）/ 全局白名单 / 插件自己的名单 / 全部放开（只统计不拦）
- **时段自定义**：高峰时段随便改，也能一键恢复官方时段
- **节假日与周末**：内置节假日表，可自己加；周末默认放行
- **用量统计**：按小时记录消息量，回头看看时段划得准不准
- **每日日报**：可选，定时把前一天的每小时用量推给你

## 安装

在 AstrBot 插件市场搜索「Token 高峰守卫」安装，或者把仓库克隆到 `data/plugins/` 下，重启 AstrBot。

## 怎么操作

两种方式，都能用：

**一、WebUI 插件配置页**，常用的就前面三样：

| 配置项 | 说明 |
| --- | --- |
| `enabled` | 总开关。关掉后谁都不拦，只默默统计 |
| `hard_lock` | 锁死模式。谷时也拦，直到关掉为止 |
| `grant` | 放行范围，默认只有管理员能说话 |

其余是细节：峰谷时段、周末开关、节假日表、提示文案和冷却、统计天数、日报时间等。

**二、聊天命令**，仅管理员可用：

```
/高峰 状态                    看现在拦不拦
/高峰 统计                    看各小时用量
/高峰 开关 on|off             总开关
/高峰 锁死 on|off             锁死模式
/高峰 锁死 文案 xxx           锁死时回什么
/高峰 放行 管理员|全局|白名单|全部   谁能说话
/高峰 白名单 加|删 <ID>       维护插件自己的名单
/高峰 模式 peak|off           peak=按峰谷拦，off=只统计
/高峰 时段 09:00-12:00 14:00-18:00   改峰谷时段
/高峰 时段 默认               恢复官方时段
/高峰 假日                    看节假日表
/高峰 假日 加 2027-01-01~2027-01-03  加节假日
/高峰 周末 on|off             周末拦不拦
/高峰 日报 on|off             每日用量日报
/高峰 日报 21:00              改日报时间
/高峰 日报 现在               立刻发一份
/高峰 重算                    重算时段缓存
/高峰 清除 确认               清空统计
```

## 说明

- 拦截发生在消息处理阶段。群聊里没被唤醒的消息本来就不会走到这一步，所以只在「机器人会搭理你」的那些消息上生效
- 提示文案支持变量：`{windows}` 高峰时段、`{until}` 放开时间、`{now}` 当前时间
- 节假日写法：`2027-01-01` 或 `2027-01-01~2027-01-03`，区间用波浪号
- 统计只存在本地 `plugin_data` 里，不上传
